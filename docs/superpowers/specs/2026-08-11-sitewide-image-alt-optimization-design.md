# 全站圖片 Alt 優化設計

## 目標

優化網站全部公開 HTML 頁面的圖片替代文字，使內容圖片具備簡短、具體且符合頁面語境的描述，並自然帶入生活牙醫的服務地區與療程搜尋詞。純裝飾圖片繼續使用 `alt=""`，避免螢幕閱讀器朗讀無意義資訊。

## 修改範圍

- 根目錄公開頁面
- `services/` 療程頁面
- `cases/` 案例頁面
- `knowledge/` 牙醫知識文章
- `taichung/` 台中旗艦店與醫師頁面
- `zushan/` 南投竹山店與醫師頁面
- `element.html` 僅稽核，不因個別 Alt 文案更新而改變元件結構

## Alt 撰寫規則

### 分店頁面

- 台中頁面使用「台中生活牙醫」或「台中生活牙醫診所」，搭配圖片實際內容，例如醫師姓名、診間設備或院所空間。
- 竹山頁面使用「南投竹山生活牙醫」或「南投竹山生活牙醫診所」，不得混用台中旗艦店資訊。

### 共用療程與案例頁面

- 療程主視覺、優勢圖、治療示意圖與案例圖，依實際內容自然加入「台中南投生活牙醫」及療程名稱。
- 不要求每張圖片都重複完整品牌詞；同一區塊應避免連續使用完全相同的 Alt。
- 將「圖片 1」、「案例照片 2」、「示意照片」等過度籠統文字改為能辨識療程與畫面用途的描述。

### 知識文章

- 以圖片實際內容與文章主題為主，不機械加入地區名稱。
- 文章封面、治療說明圖與比較圖應說明其內容或用途。
- 單純替換個別文章 Alt 不改變可重用元件語法，因此不需同步修改 `element.html`。

### 保留空 Alt 的圖片

以下圖片維持 `alt=""`：

- 已有相鄰文字完整說明功能的流程圖示與服務圖示
- LINE 浮動按鈕內的圖示（外層連結已有 `aria-label`）
- 純裝飾圖片、背景效果與無獨立資訊的圖形
- 動態燈箱尚未載入內容時使用的空圖片節點

若空 Alt 圖片本身承載文章封面、案例、設備、醫師或療程資訊，則改為具體 Alt。

## 驗證

- 全部 `<img>` 元素都保有 `alt` 屬性。
- 空 Alt 僅保留於裝飾、重複或由外層無障礙名稱取代的圖片。
- 搜尋並排除台中頁使用竹山名稱、竹山頁使用台中名稱的錯誤。
- 搜尋並改善「圖片數字」、「案例照片數字」等缺乏資訊的 Alt。
- 執行 HTML 圖片 Alt 稽核與 `git diff --check`，確認沒有語法或空白錯誤。
- 不改動圖片路徑、版面、互動、CSS 或其他既有文案。

## 完成標準

所有公開頁面的內容圖片均具有符合實際內容與頁面語境的替代文字；裝飾圖片維持空 Alt；分店、療程與 SEO 關鍵字使用自然且正確，沒有關鍵字堆砌或分店資訊混用。
