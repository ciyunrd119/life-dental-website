# 醫師案例圖片 Alt 地區前綴設計

## 目的

補齊醫師個人頁「案例分享」照片的替代文字，使 Alt 同時包含院所地區、生活牙醫、醫師姓名與案例療程內容，提升圖片語意、無障礙資訊與地區搜尋辨識。

## 套用範圍

- 台中醫師個人頁：`taichung/dr-*.html`
- 南投竹山醫師個人頁：`zushan/team/dr-*.html`
- 僅處理頁面案例分享區塊內的實質案例照片。

不處理下列圖片：

- 裝飾圖片，繼續保留 `alt=""`
- 醫師肖像、院所環境、圖示與其他非案例圖片
- 醫師列表頁、首頁或療程頁上的圖片

## Alt 命名規則

- 台中頁面：`台中生活牙醫＋醫師姓名＋原案例療程描述`
- 南投竹山頁面：`南投生活牙醫＋醫師姓名＋原案例療程描述`

範例：

- `台中生活牙醫曾吉杉醫師數位植牙後牙重建案例`
- `南投生活牙醫柳朝升醫師全口重建案例`

## 修改原則

1. 以該醫師個人頁的主標題姓名為正式姓名，不從圖片檔名猜測。
2. 保留原 Alt 中正確且具體的療程或案例描述，只補上缺少的地區、品牌與醫師姓名。
3. 已含正確完整前綴的 Alt 不重複加入文字。
4. 不改動圖片路徑、HTML 結構、CSS、版面或互動。

## 驗證

1. 掃描所有指定醫師頁的案例照片，確認台中頁 Alt 含「台中生活牙醫」，南投頁 Alt 含「南投生活牙醫」。
2. 確認案例 Alt 的醫師姓名與該頁主標題一致。
3. 確認裝飾圖片的 `alt=""` 未被更動。
4. 執行 `git diff --check`，確認沒有空白或格式錯誤。
