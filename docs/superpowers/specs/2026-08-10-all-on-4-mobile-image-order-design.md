# All-On-4 手機版圖片順序調整設計

## 目標

調整 `services/all-on-4.html` 的「數位全口重建規劃」區塊，使 640px 以下的手機版內容順序改為：

1. 兩段說明文字
2. 數位全口重建規劃圖片
3. 從「01 影像與骨質分析」開始的 01–04 規劃列表

桌機版與平板版維持現有版面，不改變文案、圖片檔案或其他區塊順序。

## 實作設計

- 在目標 `section.dsd` 加上 All-On-4 專用類別，避免影響其他共用 DSD 區塊的頁面。
- 在 `css/style.css` 的 `@media (max-width: 640px)` 內加入該專用類別的排序規則。
- 手機版將 `.dsd-text` 設為 `display: contents`，讓兩個說明段落、圖片與 `.dsd-steps` 能成為同一排序層級，再以 `order` 建立指定順序。
- 沿用現有圖片與滿版寬度規則，不複製 HTML 圖片節點。
- 保留圖片與前後內容的間距，避免圖片緊貼說明文字或 01–04 列表。

## 影響範圍

- `services/all-on-4.html`：只新增目標區塊的專用類別。
- `css/style.css`：只新增 640px 以下的 All-On-4 專用排序與間距規則。
- `element.html`：不需同步；此變更不屬於牙醫知識文章元件。

## 驗收方式

- 在約 395px 寬的手機視埠確認順序為「說明文字 → 圖片 → 01–04 列表」。
- 確認圖片維持滿版寬度，頁面無橫向溢位。
- 在桌機視埠確認說明與圖片仍維持左右雙欄。
- 檢查頁面中只有一個數位規劃圖片節點，且 HTML/CSS 差異無空白錯誤。
